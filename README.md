# Julien DOLOU — Studio digital

Site vitrine / portfolio premium pour Julien DOLOU : développement et produits numériques sur mesure.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000).

## Configuration

- Email de contact : variable d’environnement `NEXT_PUBLIC_CONTACT_EMAIL` (défaut dans `src/lib/site.ts`)
- URL du site : `src/lib/site.ts` → `siteConfig.url`

## Scripts

- `npm run dev` — développement
- `npm run build` — build production
- `npm run start` — serveur production
- `npm run lint` — lint

## Direction artistique

Palette **Obsidian Signal** : fond obsidian, accent lime signal, typographie Syne + Instrument Sans.
